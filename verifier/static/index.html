开始验收

  1. 创建验收任务，填写需求、修改前 / 修改后两个 API 地址。
  2. 导入 OpenAPI 文件，或手动定义接口。
  3. 生成 / 填写验收规则，编辑并确认（规则按版本保存，运行不会修改规则）。
  4. 在两个环境运行同样的检查。
  5. 查看逐项结果、前后差异与失败原因，导出 Markdown / JSON 报告。

想快速看效果？点击左侧「创建演示任务」，再启动两个示例服务即可。
